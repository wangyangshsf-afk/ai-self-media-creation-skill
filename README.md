# 赛道定位推荐 Skill

为已明确或正在梳理账号定位的创作者，推荐抖音、微信视频号、小红书账号赛道。

## 能力边界

- 只给 **1 个主赛道 + 2 个备选赛道**，并解释比较依据、平台适配、风险和信心。
- 不推荐具体选题，不写标题、脚本、文案、日历或发布方案。
- 可依据用户提供的信息独立工作；TrendRadar 或其他实时数据源是可选项，不是依赖。

## 安装

### 支持 Agent Skills 的平台

下载本仓库/压缩包后，将 `china-social-niche-strategy` 文件夹放入平台的 skills 目录。确保 `SKILL.md` 位于技能目录根部。不同平台的技能目录及刷新方式可能不同，请以该平台文档为准。

### 只支持系统提示词的平台

复制 `PROMPT.md` 的全部内容，粘贴到该平台的系统指令/自定义助手指令中。需要使用时提供账号定位信息并要求按规则推荐赛道。

## 需要提供的定位信息

尽量提供目标受众、个人/团队经历与专业能力、可用资源或可信证明、账号目标、目标平台、内容形式与每周可投入时间、商业化约束。信息不全时，Skill 会只追问影响判断的关键问题，或明确假设后继续。

## 文件

- `SKILL.md`: Agent Skills 标准入口，供支持技能目录的客户端读取。
- `PROMPT.md`: 模型无关的系统提示词版本，适用于只有自定义指令入口的平台。
- `agents/openai.yaml`: Codex 界面展示元数据；其他平台可忽略。
